## Homework Assignment: Build a Number Guessing Game

### Objective:

Apply your knowledge of loops, conditionals, and input validation to build an
interactive game that gives the player feedback until they guess correctly.

---

### Instructions:

Create a Python file called `guessing_game.py` that works as follows:

1. Pick a secret number. You can hardcode it for now (e.g., `secret = 42`).
2. Use a `while` loop to keep asking the player for a guess until they get it
   right.
3. After each wrong guess, tell the player whether their guess was too high or
   too low.
4. When they guess correctly, print a congratulations message and tell them how
   many guesses it took.

---

### Part 1: Basic Game Loop

Your script should:

* Print a welcome message when the game starts
* Ask the player to enter a number using `input()`
* Convert the input to an integer using `int()`
* Compare the guess to the secret number using `if`, `elif`, and `else`
* Keep a counter that goes up by one each time the player guesses
* Break out of the loop when the guess is correct

---

### Part 2: Input Validation

Not every player will type a number. Add a check so your program does not crash
if someone types a word instead.

* Wrap your `int()` conversion in a `try`/`except` block, or check
  `user_input.isdigit()` before converting
* If the input is not a valid number, print a message like
  `"Please enter a whole number."` and ask again without counting it as a guess

---

### Part 3: Final Feedback

When the game ends, print:

* How many guesses it took
* A rating based on the number of guesses:
  * 1 guess: `"Lucky shot!"`
  * 2-4 guesses: `"Nice work!"`
  * 5-9 guesses: `"You got there."`
  * 10 or more: `"Keep practicing your deduction skills."`

---

### Sample Run:

```
Guess a number between 1 and 100: 50
Too high!
Guess a number between 1 and 100: 25
Too low!
Guess a number between 1 and 100: 37
Too low!
Guess a number between 1 and 100: 42
Correct! You got it in 4 guesses.
Nice work!
```

### Bonus Challenge (Optional):

* Use `import random` and `random.randint(1, 100)` to pick a different secret
  number each time the game runs.
* Add a maximum number of guesses (e.g., 10). If the player runs out, reveal
  the answer and end the game.
