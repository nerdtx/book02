## Section 5: Working with Iterables and Generators

So far, you’ve worked with lists, dictionaries, and loops — all of which rely on something called an **iterable**. In this section, you’ll learn what iterables are, and how **generators** allow you to process data efficiently without storing everything in memory.

---

### What Is an Iterable?

An **iterable** is any object you can loop over using a `for` loop.

Examples of iterables:

* Lists: `[1, 2, 3]`
* Strings: `"hello"`
* Dictionaries: `{"a": 1, "b": 2}`
* Sets and tuples

```python
for letter in "plane":
    print(letter)
```

Each time through the loop, Python retrieves the next item from the iterable.

---

### What Is a Generator?

A **generator** is a special type of iterable that produces values **one at a time**, instead of storing them all in memory at once.

This is useful when working with:

* Large datasets
* Streams of data
* Situations where you don’t need all results at once

---

### Generator Expressions

A generator expression looks similar to a list comprehension, but uses parentheses `()` instead of brackets `[]`:

```python
numbers = [1, 2, 3, 4]

gen = (n * 2 for n in numbers)
```

This does **not** create a list. Instead, it creates a generator object.

You can loop over it:

```python
for value in gen:
    print(value)
```

---

### Key Difference: List vs Generator

```python
# List comprehension
doubled_list = [n * 2 for n in numbers]

# Generator expression
doubled_gen = (n * 2 for n in numbers)
```

* **List**: stores all values in memory immediately
* **Generator**: produces values one at a time when needed

---

### Using Generators with Built-ins

Generators work well with functions like `sum()`, `any()`, and `max()`:

```python
numbers = [1, 2, 3, 4, 5]

total = sum(n * 2 for n in numbers)
print(total)  # 30
```

Notice that no intermediate list is created — this is efficient and clean.

---

### Introduction to `yield`

You can also create generators using functions and the `yield` keyword:

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1
```

Using it:

```python
for num in countdown(5):
    print(num)
```

Output:

```
5
4
3
2
1
```

Each time `yield` runs, it returns a value and pauses the function until the next iteration.

---

### When to Use Generators

Use generators when:

* You’re working with large data
* You only need values one at a time
* You want to improve memory efficiency

Avoid them when:

* You need to reuse the data multiple times (generators are consumed once)

---

> **Helpful Hint:**
> If you find yourself building a large list just to loop over it once, consider using a generator instead.

---

### Summary

Generators allow you to:

* Work with data efficiently
* Avoid storing unnecessary intermediate results
* Write clean, pipeline-style code
