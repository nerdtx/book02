## Section 7: Type Hints and Readable Code

As programs grow larger, it gets harder to remember what types of data are flowing through your functions. **Type hints** let you annotate variables and parameters with expected types. Python doesn’t enforce them at runtime, but they make your code much easier to read and debug.

---

### What Are Type Hints?

Type hints are annotations added to variables, function parameters, and return values.

Example:

```python
def add(a: int, b: int) -> int:
    return a + b
```

This tells anyone reading the code:

* `a` and `b` should be integers
* The function returns an integer

Python does not enforce this automatically, but it provides clarity.

---

### Typing Variables

You can also add type hints to variables:

```python
name: str = "F-16"
range_km: int = 4220
```

This is especially helpful when variables are defined far from where they are used.

---

### Typing Collections

You can describe more complex data structures:

```python
planes: list[str] = ["F-16", "A-10", "Boeing 737"]

ranges: dict[str, int] = {
    "F-16": 4220,
    "A-10": 4150
}
```

This tells you:

* `planes` is a list of strings
* `ranges` maps strings to integers

---

### Typing Functions with Complex Data

You can combine these ideas:

```python
def get_long_range_planes(planes: list[dict]) -> list[str]:
    return [p["name"] for p in planes if p["range"] > 5000]
```

Even without reading the implementation, you know:

* Input: list of dictionaries
* Output: list of strings

---

### Why Type Hints Matter

Type hints provide several benefits:

* **Readability**: Others can understand your code faster
* **Documentation**: Types act as built-in documentation
* **Error Prevention**: Tools can detect mismatches before runtime
* **Editor Support**: Autocomplete and suggestions improve

---

### Optional: Static Type Checking

Tools like `mypy` can analyze your code and detect type issues:

```bash
pip install mypy
mypy your_file.py
```

This helps catch bugs early, before you even run the program.

---

### Type Hints in Your Projects

Type hints are especially useful in:

* **APIs** (clarifying request/response structures)
* **Database models** (tracking field types)
* **Functions with many parameters**
* **Team environments**

---

> **Helpful Hint:**
> Type hints should make your code easier to understand, not harder. Keep them simple and avoid overcomplicating types unless necessary.

---

Type hints are a low-cost way to make your code self-documenting and easier for tools like editors and type checkers to analyze.
