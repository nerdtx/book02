## Section 9: Practical Patterns and Mini-Examples

In this section, you’ll combine everything you’ve learned — comprehensions, lambda functions, built-ins, generators, and Pythonic style — to solve real-world problems.

Instead of learning new syntax, the goal here is to **recognize patterns** and apply the right tools together.

---

### Example Dataset

We’ll use a simple dataset of airplanes:

```python
planes = [
    {"name": "F-16", "type": "fighter", "range": 4220},
    {"name": "Boeing 737", "type": "passenger", "range": 5600},
    {"name": "A-10", "type": "attack", "range": 4150},
    {"name": "F-22", "type": "fighter", "range": 2960}
]
```

---

### Pattern 1: Filtering Data

Goal: Find all long-range planes (range > 4000)

```python
long_range = [p for p in planes if p["range"] > 4000]
```

---

### Pattern 2: Transforming Data

Goal: Extract just the names

```python
names = [p["name"] for p in planes]
```

---

### Pattern 3: Filter + Transform Together

Goal: Names of long-range planes

```python
names = [p["name"] for p in planes if p["range"] > 4000]
```

---

### Pattern 4: Sorting with Lambda

Goal: Sort planes by range

```python
sorted_planes = sorted(planes, key=lambda p: p["range"])
```

Reverse order:

```python
sorted_planes = sorted(planes, key=lambda p: p["range"], reverse=True)
```

---

### Pattern 5: Building a Lookup Dictionary

Goal: Map plane name → range

```python
range_lookup = {p["name"]: p["range"] for p in planes}
```

---

### Pattern 6: Grouping Data (Manual Pattern)

Goal: Group planes by type

```python
groups = {}

for p in planes:
    t = p["type"]
    if t not in groups:
        groups[t] = []
    groups[t].append(p)
```

Result:

```python
{
    "fighter": [...],
    "passenger": [...],
    "attack": [...]
}
```

---

### Pattern 7: Using `any()` and `all()`

Goal: Check if any plane has short range

```python
has_short = any(p["range"] < 3000 for p in planes)
```

Goal: Check if all planes exceed a threshold

```python
all_long = all(p["range"] > 2000 for p in planes)
```

---

### Pattern 8: Combining Multiple Tools

Goal: Get sorted names of long-range planes

```python
result = sorted(
    [p["name"] for p in planes if p["range"] > 4000]
)
```

---

### Pattern 9: Generator for Efficiency

Goal: Sum ranges without creating a list

```python
total_range = sum(p["range"] for p in planes)
```

---

### Pattern 10: Clean Refactoring

Before:

```python
result = []
for p in planes:
    if p["type"] == "fighter":
        result.append(p["name"])
```

After:

```python
result = [p["name"] for p in planes if p["type"] == "fighter"]
```

---

> **Helpful Hint:**
> Many problems follow the same pattern: filter → transform → sort → aggregate. Learn to recognize these steps and choose the right tools.
