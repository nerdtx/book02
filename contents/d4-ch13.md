## Section 4: Built-in Functions That Replace Loops

Python includes a powerful set of built-in functions that can often replace traditional `for` loops. These functions make your code shorter, clearer, and often more efficient.

In this section, you’ll learn how to use functions like `zip()`, `enumerate()`, `any()`, `all()`, and others to write more expressive code.

---

### Using `enumerate()`

When looping through a list, you sometimes need both the **index** and the **value**. Instead of manually tracking an index, use `enumerate()`:

```python
names = ["F-16", "A-10", "Boeing 737"]

for i, name in enumerate(names):
    print(i, name)
```

Output:

```
0 F-16
1 A-10
2 Boeing 737
```

This replaces a less clean version:

```python
for i in range(len(names)):
    print(i, names[i])
```

---

### Using `zip()`

The `zip()` function lets you loop over multiple lists at the same time:

```python
names = ["F-16", "A-10", "Boeing 737"]
ranges = [4220, 4150, 5600]

for name, r in zip(names, ranges):
    print(name, r)
```

Output:

```
F-16 4220
A-10 4150
Boeing 737 5600
```

This is especially useful when combining related data.

---

### Using `any()` and `all()`

These functions help evaluate conditions across a collection.

**`any()`** returns `True` if *any* item is true:

```python
ranges = [3000, 4000, 7000]

has_long_range = any(r > 6000 for r in ranges)
print(has_long_range)  # True
```

**`all()`** returns `True` if *all* items are true:

```python
all_long_range = all(r > 2000 for r in ranges)
print(all_long_range)  # True
```

---

### Using `min()`, `max()`, and `sum()`

These functions are useful for working with numeric data:

```python
ranges = [4220, 4150, 5600]

print(min(ranges))  # 4150
print(max(ranges))  # 5600
print(sum(ranges))  # 13970
```

You can also use them with more complex data using `key`:

```python
planes = [
    {"name": "F-16", "range": 4220},
    {"name": "Boeing 737", "range": 5600},
    {"name": "A-10", "range": 4150}
]

longest = max(planes, key=lambda p: p["range"])
print(longest["name"])  # Boeing 737
```

---

### Using `sorted()`

You’ve already seen `sorted()`, but it’s worth emphasizing how powerful it is:

```python
sorted_planes = sorted(planes, key=lambda p: p["name"])
```

You can also reverse the order:

```python
sorted_planes = sorted(planes, key=lambda p: p["range"], reverse=True)
```

---

### Combining These Tools

These built-ins often work together with:

* **lambda functions**
* **comprehensions**
* **generator expressions**

Example:

```python
has_short_plane = any(p["range"] < 4000 for p in planes)
```

This is compact, readable, and avoids creating unnecessary lists.

---

> **Helpful Hint:**
> Many Python beginners overuse loops. Before writing a loop, ask yourself: “Is there a built-in function that already does this?”

---

### Summary

These built-in functions help you:

* Replace manual loops with cleaner expressions
* Work with multiple collections easily
* Write more concise and readable code
* Leverage Python’s strengths as a high-level language
