## Section 2: Dictionary and Set Comprehensions

In the previous section, you learned how to use list comprehensions to build lists efficiently. Python extends this idea to other data structures as well — most notably **dictionaries** and **sets**.

These comprehensions allow you to construct more complex data structures in a clean and readable way.

---

### Dictionary Comprehensions

A dictionary comprehension follows this pattern:

```python
{key_expression: value_expression for item in iterable}
```

Let’s start with a simple example. Suppose you want to create a dictionary mapping airplane names to their range:

```python
planes = [
    {"name": "F-16", "range": 4220},
    {"name": "Boeing 737", "range": 5600},
    {"name": "A-10", "range": 4150}
]

range_lookup = {p["name"]: p["range"] for p in planes}

print(range_lookup)
# {'F-16': 4220, 'Boeing 737': 5600, 'A-10': 4150}
```

This replaces a longer loop:

```python
range_lookup = {}
for p in planes:
    range_lookup[p["name"]] = p["range"]
```

---

### Adding Conditions to Dictionary Comprehensions

You can filter items using an `if` condition:

```python
long_range = {
    p["name"]: p["range"]
    for p in planes
    if p["range"] > 4500
}

print(long_range)
# {'Boeing 737': 5600}
```

---

### Transforming Keys and Values

You can also modify keys and values as you build the dictionary:

```python
upper_lookup = {
    p["name"].upper(): p["range"] // 1000
    for p in planes
}

print(upper_lookup)
# {'F-16': 4, 'BOEING 737': 5, 'A-10': 4}
```

---

### Set Comprehensions

A **set comprehension** looks similar to a list comprehension but uses curly braces `{}` without key-value pairs:

```python
{expression for item in iterable}
```

Sets automatically store **unique values**, so they are useful for removing duplicates.

Example:

```python
names = ["F-16", "F-16", "A-10", "Boeing 737"]

unique_names = {name for name in names}
print(unique_names)
# {'F-16', 'A-10', 'Boeing 737'}
```

---

### Filtering with Set Comprehensions

You can also apply conditions:

```python
long_names = {name for name in names if len(name) > 4}
print(long_names)
# {'Boeing 737'}
```

---

### When to Use Each

* **List comprehension** → ordered collection, allows duplicates
* **Dictionary comprehension** → key-value mapping
* **Set comprehension** → unique values only

Each has its place depending on the structure you need.

---

> **Helpful Hint:**
> If you ever see `{...}` and expect a dictionary, make sure you're using `key: value` inside. Otherwise, Python will create a set instead!

---

### Summary

Dictionary and set comprehensions allow you to:

* Build complex data structures quickly
* Transform and filter data in a single step
* Write more expressive and concise code
