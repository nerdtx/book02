## Section 1: List Comprehensions

In earlier chapters, you used `for` loops to build lists step by step. While this works well, Python provides a more concise and expressive way to do the same thing: **list comprehensions**.

List comprehensions allow you to create new lists in a single line of code by combining iteration and transformation.

---

### Basic Syntax

A list comprehension follows this general pattern:

```python
[expression for item in iterable]
```

Let’s look at a simple example. Suppose you have a list of numbers and want to double each value:

```python
numbers = [1, 2, 3, 4]

doubled = [n * 2 for n in numbers]
print(doubled)  # [2, 4, 6, 8]
```

This replaces a longer version using a loop:

```python
doubled = []
for n in numbers:
    doubled.append(n * 2)
```

Both produce the same result, but the list comprehension is shorter and often easier to read once you’re familiar with the syntax.

---

### Adding Conditions

You can include an `if` statement to filter items:

```python
numbers = [1, 2, 3, 4, 5, 6]

evens = [n for n in numbers if n % 2 == 0]
print(evens)  # [2, 4, 6]
```

This means:

* Loop through each number
* Only include it if the condition is true

---

### Transforming While Filtering

You can both filter and transform at the same time:

```python
numbers = [1, 2, 3, 4, 5, 6]

even_squares = [n * n for n in numbers if n % 2 == 0]
print(even_squares)  # [4, 16, 36]
```

---

### Working with Strings and Objects

List comprehensions aren’t limited to numbers. They work with any iterable:

```python
names = ["alex", "jamie", "taylor"]

capitalized = [name.capitalize() for name in names]
print(capitalized)  # ["Alex", "Jamie", "Taylor"]
```

---

### Nested Comprehensions (Use Carefully)

You can nest loops inside a comprehension:

```python
pairs = [(x, y) for x in [1, 2] for y in [3, 4]]
print(pairs)  # [(1, 3), (1, 4), (2, 3), (2, 4)]
```

However, these can become hard to read quickly.

> **Helpful Hint:**
> If a list comprehension becomes difficult to read in one glance, it’s better to switch back to a standard `for` loop. Clarity is more important than cleverness.

---

### When to Use List Comprehensions

Use list comprehensions when:

* You are creating a new list from an existing iterable
* The logic is simple and readable
* You want to combine transformation and filtering

Avoid them when:

* The logic is complex or nested deeply
* You need multiple steps or side effects

---

List comprehensions let you write shorter, more expressive code by combining loops and transformations into a single readable line.
