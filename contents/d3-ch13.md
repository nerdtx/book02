## Section 3: Lambda Functions

So far, you’ve used functions defined with `def` to organize your code. Python also provides a way to define **small, one-line functions** without giving them a name. These are called **lambda functions**.

Lambda functions are useful when you need a quick function for a short period of time — especially when working with sorting, filtering, or transforming data.

---

### What Is a Lambda Function?

A lambda function is an **anonymous function** — meaning it has no name. It follows this pattern:

```python
lambda parameters: expression
```

Example:

```python
double = lambda x: x * 2

print(double(5))  # 10
```

This behaves just like:

```python
def double(x):
    return x * 2
```

---

### When to Use Lambda Functions

Lambda functions are most useful when:

* The function is short (usually one line)
* You only need it temporarily
* You don’t want to define a full function with `def`

---

### Using Lambda with `sorted()`

One of the most common uses of lambda functions is customizing how data is sorted.

Example:

```python
planes = [
    {"name": "F-16", "range": 4220},
    {"name": "Boeing 737", "range": 5600},
    {"name": "A-10", "range": 4150}
]

sorted_planes = sorted(planes, key=lambda p: p["range"])

for p in sorted_planes:
    print(p["name"], p["range"])
```

This sorts the planes by their `range`.

---

### Using Lambda with `map()`

The `map()` function applies a transformation to each item:

```python
numbers = [1, 2, 3, 4]

doubled = list(map(lambda x: x * 2, numbers))
print(doubled)  # [2, 4, 6, 8]
```

This is similar to a list comprehension:

```python
doubled = [x * 2 for x in numbers]
```

---

### Using Lambda with `filter()`

The `filter()` function selects items based on a condition:

```python
numbers = [1, 2, 3, 4, 5, 6]

evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4, 6]
```

Again, this is often replaced by a list comprehension:

```python
evens = [x for x in numbers if x % 2 == 0]
```

---

### Lambda vs List Comprehensions

In modern Python, list comprehensions are usually preferred for readability. Lambda functions still shine in cases like:

* Custom sorting (`sorted(..., key=lambda ...)`)
* Short transformations passed into other functions

---

### Limitations of Lambda Functions

Lambda functions:

* Can only contain a single expression
* Cannot include statements like `if/else` blocks (except inline expressions)
* Can become hard to read if overused

> **Helpful Hint:**
> If your lambda is getting long or complicated, stop and use a regular `def` function instead. Clear code is better than clever code.

---

### Summary

Lambda functions allow you to:

* Define small, temporary functions inline
* Customize behavior in functions like `sorted()`, `map()`, and `filter()`
* Write more concise code in specific situations
